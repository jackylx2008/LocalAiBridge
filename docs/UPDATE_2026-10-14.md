# 2026-10-14 更新说明：参考图图标与 Windows 交付目录

## 图标

- 按用户提供的机器人参考图直接转换，不重新绘制，不裁剪，也不调整颜色、轮廓或比例。
- 原始文件保存在 `icons/LocalAIBridge-reference.jpg`。收到的文件虽以 `.png` 命名，实际编码为 JPEG；这里只更正扩展名，未改变原始文件内容。
- `icons/LocalAIBridge.png` 为 2048 × 2048。它与原始 JPEG 解码后的 RGB 像素逐一一致，包括浅色背景和阴影。
- 同一 PNG 生成 `icons/windows/LocalAIBridge.ico` 与 `icons/macos/LocalAIBridge.icns`。ICO 包含 16、20、24、32、40、48、64、128、256 像素帧；这些平台尺寸按要求缩小，未改变画面比例。
- `icons/generate_local_ai_bridge_icon.py` 现为纯转换脚本。默认读取 `icons/LocalAIBridge.png`，也可指定新的方形原图路径。

重新转换参考图：

```powershell
.\.venv\Scripts\python.exe icons\generate_local_ai_bridge_icon.py icons\LocalAIBridge-reference.jpg
```

## Windows EXE

- `build_windows_exe.ps1` 现在将单文件程序输出到 `build/delivery/LocalAiBridge.exe`。
- 从项目中的 `build/delivery` 运行时，程序会继续在项目根目录查找 `common.env` 和 `config.yaml`；放到其他位置时，优先使用 EXE 同目录的配置。默认 `config.yaml` 和窗口图标内置在 EXE 中。
- `common.env`、模型、llama.cpp 和本机密钥不会打进 EXE。`build/` 在 `.gitignore` 中，交付文件需在目标 Windows 环境运行打包脚本生成。

构建命令：

```powershell
.\build_windows_exe.ps1
```
